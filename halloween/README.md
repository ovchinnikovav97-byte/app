# Visit Siberia! · Vika’s Birthday Expedition · 31.10.2026

Страница save the date и ответов гостей на день рождения Вики: «The Eye of Siberia», авторская
ролевая игра «The Black Tears of Baikal». Гость «оформляет туристическую визу»: отвечает, едет
ли, сколько с ним спутников, какую страну представляет и какое блюдо везёт.

**Ссылка для гостей:** https://ovchinnikovav97-byte.github.io/app/halloween/
Язык выбирается по телефону гостя. Можно отправить ссылку сразу на нужном языке:
`?lang=ru`, `?lang=fr`, `?lang=en` в конце адреса.

## Откуда дизайн

Постер «Baikal Black Tears Poster» Вики в Claude Design (10.10.2026): палитра, шрифты
Bodoni Moda / Josefin Sans / Rock Salt, иллюстрация Байкала, штамп-виза. Иллюстрация перенесена
в `index.html` без изменений. У этих трёх шрифтов нет кириллицы, поэтому русская версия
набрана их ближайшими родственниками с кириллицей: Playfair Display, Jost и Caveat.

## Что где

| Файл | Зачем |
|---|---|
| `index.html` | вся страница; настройки вечеринки в блоке `party-config` в начале файла |
| `apps-script/Code.gs` | код для Google-таблицы, куда падают ответы гостей |
| `party-en.ics`, `party-fr.ics`, `party-ru.ics` | «Добавить в календарь» для Apple и Outlook |
| `og.jpg` | превью, когда ссылку отправляют в мессенджере (1200×630, лёгкий JPEG для WhatsApp) |
| `tools/make-ics.mjs` | пересобрать календари после смены даты или времени |
| `tools/og.html`, `tools/render-og.mjs` | исходник и сборка превью |

## Частые правки

- **Время, дедлайн, ссылка на таблицу:** значения в `party-config` в `index.html`.
  После смены даты или времени: `node halloween/tools/make-ics.mjs`.
- **Адрес:** поле `address` в `party-config` нарочно пустое (репозиторий публичный).
  Удобнее вписать адрес в скрипт таблицы (`PRIVATE_DETAILS`): его увидят только гости,
  ответившие «да», в своей визе.
- **Превью ссылки:** мессенджеры кэшируют его, поэтому менять лучше до рассылки.

## Приватность

Репозиторий публичный. Здесь нет адреса улицы, телефонов и имён гостей. Ответы хранятся только
в Google-таблице Вики; страница показывает лишь, какие страны уже «на борту». Страница закрыта
от поисковиков (`noindex`).

Настройка таблицы по шагам и журнал всего процесса лежат в приватном second brain:
`02_PROJECTS/halloween_party/`.
