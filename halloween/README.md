# Halloween around the world · 31.10.2026

Страница save the date и ответов гостей на Хэллоуин-день рождения Виктории.

**Ссылка для гостей:** https://ovchinnikovav97-byte.github.io/app/halloween/
Язык выбирается по телефону гостя. Можно отправить ссылку сразу на нужном языке:
`?lang=ru`, `?lang=fr`, `?lang=en` в конце адреса.

## Что где

| Файл | Зачем |
|---|---|
| `index.html` | вся страница; настройки вечеринки в блоке `party-config` в начале файла |
| `apps-script/Code.gs` | код для Google-таблицы, куда падают ответы гостей |
| `party-en.ics`, `party-fr.ics`, `party-ru.ics` | «Добавить в календарь» для Apple и Outlook |
| `og.png` | картинка-превью, когда ссылку отправляют в мессенджере (1200×630) |
| `save-the-date.jpg` | твой дизайн save the date; появится на странице сам, как только файл ляжет сюда |
| `tools/` | пересборка календарей и превью после смены даты, времени или названия |

## Частые правки

- **Дизайн save the date:** загрузить картинку в эту папку под именем `save-the-date.jpg`
  (или `.png`). Страница покажет её вместо большого заголовка. Вертикальная 4:5 смотрится лучше всего.
- **Время, дедлайн, ссылка на таблицу:** поменять значения в `party-config` в `index.html`.
  После смены даты или времени пересобрать календари: `node halloween/tools/make-ics.mjs`.
- **Превью ссылки:** заменить `og.png` своей картинкой 1200×630. Мессенджеры кэшируют превью,
  поэтому лучше сделать это до рассылки.

## Приватность

Репозиторий публичный. Здесь нет и не должно быть адреса, телефонов и имён гостей.
Ответы хранятся только в Google-таблице Виктории; страница показывает лишь, какие страны
уже выбраны. Адрес (если нужен на странице) вписывается только в редакторе Apps Script,
его видят гости, ответившие «да». Страница закрыта от поисковиков (`noindex`).

Настройка таблицы по шагам и журнал всего процесса лежат в приватном second brain:
`02_PROJECTS/halloween_party/`.
